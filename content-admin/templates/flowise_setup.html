Connect to Flowise

Flowise has no supported way to hand out an API key automatically — a one-time manual step is unavoidable:

  1. Open your Flowise instance and create your admin account, if you haven't already.
  2. Go to Settings → API Keys → Create Key.
  3. Under Permissions, check every box under Chatflows, Agentflows, Credentials, and Variables — that's everything this GUI actually calls. Leave other categories (Tools, Document Stores, Assistants, …) unchecked; nothing here uses them.
  4. Paste the key below.
